## 1. 背景与目标

**背景**：初版界面功能齐全，但在手机上看起来平淡；记录页七张大卡要滑很久；指数页最重要的数字不显眼；各页间距、字号、返回链接不统一。家庭成员也缺少「坚持记录」的动力。

**目标**：

- 以 390px 手机竖屏为准，统一排版和组件
- 改成鲜艳的彩色风格，每个分页一种主色
- 记录页更短，一眼看出今天该记哪几项
- 指数页一眼看出数值和离健康区多远
- 用连续天数、今日进度、徽章、排行榜鼓励坚持记录，**只奖励记录习惯，不拿健康结果发奖**

**DoD**

- [x] 所有页面在 390px 宽下没有横向滚动，可点区域至少 44px，输入字号 16px
- [x] 每页页顶是所在分页主色的渐变横幅；详情页横幅里有白色返回
- [x] 记录页：横幅有今日进度环和连续天数；该测、逾期的行有彩色描边；暂时不用记的行默认收起
- [x] 记录页：输入框占位字带上次数值；走势折叠；保存按钮固定在底栏上方并显示已填几项
- [x] 体重任何年龄都每天记；超过 20 岁的成员身高记过一次后不用再更新
- [x] 指数页：数值放大着色，带状态标签和 0–2 的偏离刻度条
- [x] 七项指标、八个指数各有一个说明它是什么的图标
- [x] 「我」有连续天数、最长连续、徽章墙
- [x] 群组页可在综合、本周、徽章三个排行榜之间切换
- [x] `bundle exec rspec` 全部通过（63 个用例）
- [ ] 真机上看扫码、刘海和底部横条安全区

**非目标**

- 改指数公式、界值、偏离分算法
- 新建数据表或迁移；激励数据全部现算
- 用健康结果发奖励、做进步榜（见 §10）
- 深色模式、动画入场、推送提醒
- 英文界面

## 3. 各页

### 3.1 记录

- 横幅：日期与星期、今日进度环（今天已记 / 应记，记满变成对勾）、🔥 连续天数、年龄、性别（未填时为虚线按钮链到「我」）
- 测量日一行
- 指标行：图标块、名称与单位、时效小字、状态标签；输入框占位字为「上次 70」，血压为「收缩压 118」「舒张压 76」
- 该测（绿）、逾期（黄）的行有 2px 彩色描边
- 走势折叠为「走势 · 最近 N 次」，展开后仍是服务端画的细线
- **未到下次、以及成年后无需更新的行收进「暂时不用记 · N 项」折叠区**，默认关闭；其中有填过的值或报错时自动展开
- 从未记录的行仍排在折叠区之前，标签为「未点亮」并带灯泡
- 保存按钮固定在底栏上方，显示「保存本次记录（N 项）」，血压两个框算一项；提交时显示「保存中…」
- 桌面浏览器里滚轮停在已聚焦的数字框上时先让它失焦，避免滚动改动数值

### 3.2 指数

- 横幅：依据说明、综合偏离大字和状态、刻度条
- 结论放进一张卡片；「综合偏离」作为一行入口
- 分组标题加状态小标签
- 卡片：图标块、名称、数值（偏离色、加大）、状态标签、箭头、偏离刻度条；心血管的血压和心率分两行
- 缺资料时「填写性别 / 出生日期」为虚线小按钮；过期提示带时钟图标
- 单指数图：横幅里是名称、数值、状态、刻度条；时间范围用分段切换；图下加色带说明（无色带的图不显示）
- 综合偏离：横幅 + 卡片里的综合分和棒棒糖，刻度 0.5 / 1 / 1.5

### 3.3 群组

- 列表：横幅里是「创建」「加入」两个按钮；群组行有首字图标和人数；没有群组时有说明
- 群组页：横幅右上「分享」；**排行榜分段切换**（§5）；前三名领奖台；名单（名次徽章、名字、🔥 连续天数、说明、数值）；「管理」区放移除、退出、删除
- 分享：二维码在前；代号按四位分组显示 `ABCD EFGH`；复制后两秒恢复按钮文字
- 加入：分段切换标出当前方式；代号输入框为等宽大字，自动大写
- 代号带空格或小写也能识别（`GroupCode.parse`）

### 3.4 我

- 横幅：首字头像、显示名、邮箱，三格统计：连续天数、最长连续、徽章数
- 徽章墙（§4.3）
- 资料表单：性别和出生日期并排
- 「记录」「账号」两组列表；退出登录在最后一行，红字

### 3.5 其余

纠正误输入、修改一条、改善建议、登录、注册都换上横幅与卡片。纠正列表里不是今年的记录显示年份。

## 4. 记录激励（`Gamification::Progress`）

和指数一样现算，不落库。只看「记录」这件事。

### 4.1 连续天数

- 从今天往回数，每天至少有一条任意指标的记录
- 今天还没记不算断：今天没有记录时从昨天开始数
- 最长连续：历史上最长的一段

### 4.2 今日进度

`今天已记的项 / (今天已记的项 ∪ 该测和逾期的项)`。今天什么都不该记、也没记时，环为满。

### 4.3 徽章

| 徽章 | 条件 | 会不会熄灭 |
|------|------|------------|
| 初次点亮 | 至少一条记录 | 不会 |
| 一周不断 | 最长连续 ≥ 7 天 | 不会 |
| 坚持一月 | 最长连续 ≥ 30 天 | 不会 |
| 全部点亮 | 七项指标都记过 | 不会 |
| 准时达人 | 全部点亮，且当前没有逾期项 | 会，补记后重新点亮 |
| 百次记录 | 累计 100 条 | 不会 |

## 5. 排行榜（`Groups::Leaderboard`）

群组页分段切换，地址带 `?board=`，默认综合。

| 榜单 | 排序依据 | 方向 | 谁参加 |
|------|----------|------|--------|
| 综合 | 综合偏离分（沿用 `Groups::Ranking`） | 越小越好 | 未满 6 岁不排名，规则不变 |
| 本周 | 最近 7 天里有记录的天数 | 越大越好 | 所有成员；0 不给名次 |
| 徽章 | 已点亮的徽章数 | 越大越好 | 所有成员；0 不给名次 |

- 并列同名次，下一名跳过（1、1、3）
- 领奖台按名次放大头像，并列第一时两人同样大小
- 名单上的说明随榜单变：综合为口径句，本周为「今天已记 N 项」，徽章为「累计 N 条记录」
- 名单上每人名字旁仍显示 🔥 连续天数，但不再单独排名
- 曾有「连续」榜，2026-10-19 按你的要求取消。旧地址 `?board=streak` 回到综合

### 5.1 综合：谁离健康区最近

- **目的**：让家人看到彼此的身体状况，互相提醒。这是唯一一个跟健康结果有关的榜单。
- **怎么算**：取每人当前可计算指数的偏离分平均值。**分数越小越好**，0 表示算得出的指数都在健康区，1 表示平均到了警告界。
- **怎么往前排**：让偏离的指数回到健康区，多记录不会提高名次。
- **谁参加**：满 18 岁按成人界值；6 岁到未满 18 岁按学龄界值；未满 6 岁不排名。
- **注意**：缺数据的人可算的项目少，分数可能偏低。每行写着「N 项可算」，比较时要看这一句。

### 5.2 本周：最近谁记得勤

- **目的**：鼓励大家经常记录。偶尔漏一天不要紧，不会像连续天数那样清零。
- **怎么算**：今天和前 6 天里，有记录的天数，最多 7 天。
- **怎么往前排**：每天至少记一项。哪一项都行，一天记几项也只算 1 天。
- **滚动**：每天更新，8 天前的记录自动不算。
- **谁参加**：所有成员，包括孩子。0 天不给名次。

### 5.3 徽章：谁坚持得久、记得全

- **目的**：给长期坚持一点成就感，也奖励把七项指标都记全。
- **怎么算**：已点亮的徽章数，最多 6 枚，越多越好。
- **怎么往前排**：去「我」页面看还没点亮的徽章和条件。

| 徽章 | 条件 |
|------|------|
| 初次点亮 | 记下第一条 |
| 一周不断 | 连续 7 天都有记录 |
| 坚持一月 | 连续 30 天都有记录 |
| 全部点亮 | 七项指标都记过 |
| 准时达人 | 全部点亮，且没有逾期项 |
| 百次记录 | 累计 100 条 |

- **会不会掉**：只有「准时达人」会在有逾期项时熄灭，补记后重新点亮。其余拿到就不会掉。
- **谁参加**：所有成员，包括孩子。0 枚不给名次。

> 本周和徽章两个榜单只看记录习惯，不看健康结果。这样孩子和已经很健康的人也能有名次，也不会鼓励为了排名去节食。

## 6. 产品规则调整

### 6.1 体重每天记；超过 20 岁身高不用更新

- 体重：任何年龄都是每天
- 身高：`Metrics::Catalog::Entry#interval_for(years)` 在 **超过 20 岁**（整岁年龄 ≥ 21）时返回 `nil`，表示记过一次之后不用再更新。记录页这一行状态为「无需更新」，小字「N 天前记录，成年后无需更新」，收进折叠区；指数页不再提示身高过期
- 成年人从没记过身高时仍是「未点亮」，因为 BMI、腰高比等需要它
- 20 岁及以下、或没填出生日期时，身高仍是每年一次
- 其他指标不随年龄变
- 记录页时效、指数页「已超过建议记录时间」、今日进度共用同一个间隔

### 6.2 暂时不用记的项收起

见 §3.1。只影响展示，不改时效计算和排序。

## 10. 待讨论：进步榜

用健康结果排名会让未成年人和已经在健康区的人吃亏，所以本版没有做。若要做，建议：

1. 比较 30 天前与现在的综合偏离分，下降越多越靠前
2. 已在健康区（偏离分 0）的人不排名，标「保持健康区」
3. 只有满 18 岁的成员参加
4. 30 天前没有可算指数的人显示「数据不足」

待你确认 1–3 后再实施。
